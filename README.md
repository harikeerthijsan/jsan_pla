# JSAN PLA Quality Validation Workbench v3.1 — Dynamic Profile Deployable

This is the development package for a **dynamic, multi-dataset PLA/LiDAR QC workbench**. It is not tied to Sample1. Reviewers upload a COLLECTION workbook plus LAS/LAZ/COPC, the worker converts/normalizes LiDAR, rebuilds delivery geometry, runs QC, maps poles to LiDAR blocks, and opens a synchronized engineering review workspace.

## Why v3 changed

Delivery feedback was that the **MicroStation + TerraScan profile workflow is easier to analyze than a single 3D viewer**. TerraScan's tower/span workflow is built around synchronized top, longitudinal profile and section views. v3 copies that interaction model into the JSAN browser workbench.

The center workspace now has four synchronized views:

1. **Plan / Top** — span-aligned corridor
2. **Longitudinal Profile** — station vs elevation
3. **Cross Section** — offset vs elevation at a movable station
4. **3D Perspective** — COPC point cloud + delivery overlay

The profile/cross-section LiDAR points are generated by the backend worker with PDAL. This is deliberate: Potree's native profile UI has known open issues when the source is COPC, so the workbench does not depend on that path for engineering QC.

## Dynamic processing flow

```text
Upload COLLECTION.xlsx + LAS/LAZ/COPC
        |
        v
Background worker
  - LAS/LAZ -> COPC
  - CRS assignment when source SRS is absent
  - workbook parsing
  - delivery 3D reconstruction
  - QC rules
  - pole -> LiDAR block mapping
        |
        v
READY FOR REVIEW
        |
        v
Select Pole / Finding
        |
        +--> relevant COPC in 3D
        +--> Plan view
        +--> PDAL longitudinal profile
        +--> PDAL cross section
        +--> QC evidence + reviewer decision
```

## Important implementation choice

LiDAR section extraction uses **COPC spatial selection** with a bounding corridor and a resolution limit, then transforms points into a local span coordinate system:

- `station` = distance along primary pole -> target pole
- `offset` = perpendicular distance from the span axis
- `z` = elevation

This means the same sampled points can drive Plan, Profile and Cross Section while the 3D panel continues to stream the original COPC.

C:\PLA_QC\PLA_QC_Workbench_Dynamic_v3_Profile
```

```

## Reviewer workflow

1. Select a dataset.
2. Select a pole or click a finding.
3. The application chooses a target pole from the QC relationship; if none exists it uses the nearest measurable pole.
4. The 3D panel loads the relevant COPC block(s).
5. The worker builds/caches a LiDAR corridor profile.
6. Review the same evidence in Plan, Longitudinal Profile, Cross Section and 3D.
7. Click the profile or plan view to move the cross-section station.
8. Change corridor width/resolution when needed.
9. Record `CONFIRMED_FAIL`, `ACCEPTED_EXCEPTION`, `NEEDS_FIELD_REVIEW`, `CORRECTED` or reopen the finding.
